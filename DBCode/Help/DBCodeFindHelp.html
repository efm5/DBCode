Find And Search/Replace Dialogs

DBCode has two dialogs which are visually quite similar. One is used to find text (the Find dialog), the other is used to search out and replace text.

Both of these dialogs are extremely similar to one another. The Find dialog has a single ComboBox at the top; the Search/Replace dialog has two ComboBoxes. They both have identical “Options” Group Boxes and “Scope” GroupBoxes. Both dialogs have Bottom Panels which contain the Buttons which initiate the actions.

These draggable dialogs may not be resized but may be moved by dragging them via their outer borders. By default, the top border is a bit larger than the other three borders. These border sizes may be modified by the user on the Options’ General Page.

The Options GroupBox

The “Match Case” CheckBox, when checked, forces the find or search term to be case–sensitive.

The “Whole Word” CheckBox, when checked, forces the find or search term to match whole words only.

The “Regular Expressions” CheckBox, when checked, causes the find or search and replacement to be performed either by the built–in .NET Regular Expressions library or by the PCRE Regular Expressions library.

The “Verbose” CheckBox (Find dialog only), when checked, presents the user with a list of all of the found matches.

The “Use PCRE” CheckBox, when checked, specifies that the PCRE Regular Expressions library (Perl Compatible Regular Expressions) is to be used. This library is more comprehensive than that built into .NET and its pattern construction is quite different.

The Scope GroupBox

The “Selection” RadioButton, when selected, specifies that only that portion of the text which is selected will be searched. If nothing is selected, nothing is searched.

The “Global” RadioButton, when selected, specifies that all texts will be searched regardless of what might or might not be selected.

The Find Dialog

The Find BottomPanel

The Find dialog’s BottomPanel has three buttons: “Help”; “Find”; and “Cancel”. The “Help” Button brings up context–sensitive help (this HTML document) in the user’s preferred browser. The “Find” Button initiates the search for the specified term using the specified options and scope. The “Cancel” Button immediately closes the dialog without performing a search.

The Search/Replace Dialog

The Search/Replace BottomPanel

The Search/Replace dialog’s BottomPanel has four buttons: “Help”; “Replace”; “Replace All”; and “Cancel”. The “Help” Button brings up context–sensitive help (this HTML document) in the user’s preferred browser. The “Replace” Button initiates the search for the specified term using the specified options and scope and replaces the first instance found with the specified replacement. The “Replace All” Button initiates the search for the specified term using the specified options and scope and replaces all instances found with the specified replacement. The “Cancel” Button immediately closes the dialog without performing a search.
