Theme Picker

This “Theme Picker” dialog can be used to pick a “Theme” for either editing or for use as the current theme.

DBCode’s Theme Picker Dialog:

Each Button is themed (font and color scheme) based on the theme it represents. The Panel background is a neutral gray (128, 128, 128) so that these Buttons’ theme stands out better.

There is a phrase just below the title of the dialog specifying for what the picked theme will be used — it can be opened in the editor (“Edit”) or it can be set as the current theme (“XXX” — being applied immediately). [TODO: get the wording for current theme]

When a Button is clicked, its represented theme will be immediately employed (either to edit or use as the current theme); The “Theme Picker” dialog will close immediately.

The “Help” Button opens this HTML file in the user’s preferred browser. The “Cancel” Button closes the “Theme Picker” dialog immediately without making any Theme choice.
