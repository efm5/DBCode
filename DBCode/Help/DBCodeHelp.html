The Menu

The menu has 8 items: “Edit”; “Targeting”; “Visibility”; “Mode”; “Language”; “Options”; “Theme”; and “Help”. All of these items have accelerator keys. All menu items and their children have accelerator keys and keyboard shortcuts (when the they have no children).

The Edit Menu (ALT+e)

The menu images reflect a current working version of the keyboard shortcuts. After the menu has completely stabilized these keyboard shortcuts will be updated in the code and documentation.

The Edit menu has nineteen subitems: Undo; Redo; Select All; Select None; Cut; Delete; Trim To Beginning; Trim To End; Copy; Copy All; Copy To Beginning; Copy To End; Paste; Find; Find Next; Find Previous; Replace; GoTo; and Wordwrap.
