Dialogs

DB Code has a few draggable dialogs which act as though they were modal (blocking) but which are not really — because Dragon often does not find modal dialogs friendly.

These draggable dialogs may not be resized but may be moved by dragging them via their outer borders. By default, the top border is a bit larger than the other three borders. These border sizes may be modified by the user on the Options’ General Page.

The Get Integer Dialog

DBCode’s GoTo dialog:

The “GoTo” dialog is an example of the more general “Get Integer” dialog. All “Get Integer” dialogs will have a general descriptive title at the top, below that there will be a More specific prompt suggesting what the integer’s range (inclusive) is (the NumericUpDown Control will enforce this limit). Below that, to the left, is a prefix button; immediately to its right is a NumericUpDown Control into which the user may dictate (or type) an appropriate integer.

The “GoTo” dialog allows the user to move directly to a specific line, by number.

The Get String Dialog

DBCode’s Get String dialog:

The “Enter Theme Name” dialog is an example of the more general “Get String” dialog. All “Get String” dialogs will have a general descriptive title at the top, below that there will be a more specific prompt suggesting for what the string is to be used. (This is in reality a prefix button). Below that is a text box into which the user may dictate (or type) appropriate text.

The “Enter Theme Name” dialog asks the user to provide a name for the Theme.

The Find And Search/Replace Dialogs

These two dialogs are presented here, briefly, because they are draggable dialogs. However, they are sufficiently complicated to deserve a page of their own: Find And Search/Replace Dialogs

The Find Dialog

DBCode’s Find dialog:

The “Find” dialog (menu: Edit ⟩ Find Ctrl+f) allows the user to find specific strings within the text.

The Search/Replace Dialog

DBCode’s Search/Replace dialog:

The “Search/Replace” dialog (menu: Edit ⟩ Replace Ctrl+h) allows the user to search and replace specific strings within the text.
